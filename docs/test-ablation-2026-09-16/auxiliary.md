# Supplemental acceptance automation inventory and baseline

No repository files changed in this lane. No supplemental entry point was removed. This is inventory, contract evaluation and baseline execution, **not a successful ablation experiment**: no full/reduced paired mutant campaign was run for these scripts.

## Inventory and retained contracts

- `backend/scripts/acceptance_case.py` + `acceptance_recipes.json`: 20 recipes, 84 pytest-file references spanning 31 distinct files. These are selection/evidence recipes, not 84 distinct tests. Snapshot source binding, fresh JUnit evidence, required evidence presence and non-skipped cases are additional acceptance contracts.
- `acceptance_extras.py`: 6 UI recipe mappings, 6 recovery recipe mappings; A16 retains explicitly historical Temporal/Prefect/Hatchet comparison evidence; A18 checks dependency boundaries; A14 and `local-workflow-loop` invoke Compose; `project-completion` repeats backend/frontend quality gates, root image build, version consistency and demo contract checks. Repeated invocations may be costly, but retained because no paired fault experiment proves their campaign/evidence obligations redundant.
- `acceptance_compose.py`: owned stack builds; three owning database roles with six denied cross-database connections; public API and browser acceptance; all execution dependencies stopped followed by historical-read check; owned cleanup diagnostics. Not run in this lane (image builds + complete stack not repeated alongside whole-suite baseline); not counted as passing or valueless.
- `verify_goal_case.py`, `goal_verification/{workspace,native,case_evidence}.py`: 35 recipes; group incidences: real 29, backend 25, e2e 22, frontend 19, fault 11, finance 4, static 2, runner-check 2. Groups cache by source identity and validate current evidence integrity; recipe count is not test count. Native groups dispatch existing pytest, Vitest, Playwright and Finance suites. Full campaigns not re-run here; historical evidence was not reused as fresh results.
- `goal_verification/real.py` and its helper directory: fresh real-provider workflows; model-directed tool calls; observed provider output-budget protocol/enforcement; source-note provenance and filtering; natural schedule after browser close; read/write unknown effects and confirmed reconciliation; temporal history/Notes double-offline historical reads; cleanup ownership. These use genuine configured model/provider calls and were deliberately not executed (cost/credential/provider authorization unavailable to this lane). Syntax checks are not behavioral substitutes.
- `frontend/scripts/goal-verification-browser.mjs`: online/offline current-run comparison; keyboard export/copy; clipboard equals downloaded Markdown; model usage equals API; persisted metadata does not change immutable runs; Notes provenance/filter/navigation; comparison persistence; consistent read-vs-write unknown state; scheduled attention action. Four viewport widths (375/768/1024/1440) assert no horizontal overflow, positive in-bounds interactive-control bounds, focus and trial-click usability. Screenshots are evidence, not pixel-diff assertions. This does not prove full accessibility or UX quality.
- `frontend/scripts/goal-verification-schedule.mjs`: saved schedule displayed and browser closes strictly before planned natural fire. Not executed without the real campaign's current run/schedule evidence.
- `coreartifact_recovery.py`: independent Temporal server; two executable bundles, old execution retains old bytes after killed worker, new run gets new bytes, confirmed activity not replayed, missing/tampered artifact rejected, owned worker shutdown. Retained as distinct fixture-worker recovery evidence.
- `verify_platform_recovery.py` + `platform_recovery_provider.py`: complete controlled-provider platform/plugin upgrade/recovery with immutable package/model/plugin/Core snapshot, deduplication of persisted writes, artifact integrity, evidence parentage, unknown interrupted attempts, no secret bytes in history/artifacts, owned cleanup. Not equivalent to the fixture-worker probe above.
