# Backend API Guide

- `platform_router.py` assembles the `/api` platform routes. Finance serves Templates and Reports in its independent plugin process; do not mount plugin business routers in the core API.
- Return explicit response schemas; raw service or ORM objects must not bypass secret-safe read projection.
- Keep literal package `/import` and `/validate-manifest` routes before `/{package_key}`. Preserve diagnostic paths and source locations from the shared compiler instead of adding a second HTTP validator. Batch imports return one outcome per source; an HTTP success does not imply every item succeeded, and invalid sources must not prevent valid siblings from importing.
- `platform_resources.py` installs release descriptors and toggles plugins through `/plugins`; catalog and health reads use stored metadata. Explicit launch admission resolves only the selected workflow's enabled plugin bindings.
- Resource credentials are write-only; `ResourceRead` exposes presence and revision, never values. Run/result and stored schedule/fire reads must remain available without initializing the execution engine; schedule previews and mutations depend on `get_schedule_service`.
- Manual launch, rerun, input reuse, schedule creation and schedule-trigger requests carry stable caller identities. An uncertain response must be retried with the same identity; a trigger receipt or cancellation request is not a completed Run. Preparation returns the reviewed package revision and binding token; launch admission validates them through `LaunchService`. Rerun and input reuse retain the original package revision and source Run provenance.
- `platform_runs.py` owns result and input-reuse routes. Preserve `snapshotAt` across history pages so concurrent inserts do not shift pagination; apply search, filters and sorting in `../infrastructure/run_history.py`, not to an already limited page.
- `task_presets.py` persists optional bookmarks and business inputs through `TaskPresetStore`; preset writes do not launch, schedule or edit a package. Preserve explicit `hasParameters` so a saved JSON null differs from a bookmark, and revalidate against the current package revision. `connection_presets.py` exposes validated deployment defaults without credentials or service probes.
- API route-presence tests inspect `app.openapi()["paths"]`, avoiding private FastAPI include-router internals. For response behavior, use `TestClient` and `test_platform_api.py`, `test_core_api.py` or `test_target_schedules.py` in `backend/tests/`.
